# 情绪知了 · 本地文件版（v0.3）

双击 HTML 使用的五步情绪日志。保留原界面、字段、认知扭曲说明、只读历史、删除和趋势分析。**无密码、无加密；日志直接保存到本人选择的本地 JSON 文件，不使用浏览器存储。**

## 下载与使用

1. [下载 emotion-vault.html](https://github.com/apcg2/emotion-vault/releases/latest/download/emotion-vault.html)，保存到固定文件夹。用最新版**桌面 Chrome 或 Edge**双击打开，无需 Node.js、依赖、终端或服务器。Source code ZIP 是开发源码，不是成品。
2. 首次点击 **“新建日志文件”**，选择保存位置，例如 HTML 所在文件夹，使用默认名称 `emotion-logs.json`。浏览器要求选择文件并授权，这是安全限制，无法省略。
3. 开始记录。点击保存后，日志写入该 JSON；历史中的确认删除也写入同一文件。界面只有在写入结束并读回核对后，才显示保存成功。
4. 下次双击 HTML，点击 **“打开日志文件”**，选择之前的 JSON 即可继续。无需密码。每次新打开或刷新都需重新选择文件；文件引用只保留在本次页面内存中。

```text
情绪知了/
├── emotion-vault.html   程序
└── emotion-logs.json    你创建的明文日志（默认不随程序提供）
```

HTML 不会自动获得旁边文件的写入权限，也无法擅自知道你要用哪个数据文件。保存位置由你选择，文件名会显示在首页；浏览器通常不向网页透露完整磁盘路径。Firefox、Safari 或受管浏览器可能不支持文件选择/写入，页面会提示，不会悄悄改用浏览器缓存。[文件访问权限说明](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)

## 数据与安全

- **从零开始**：新版不读取、迁移、解密或删除旧版浏览器日志；不接受旧加密备份。旧加密版保留在 [v0.2.0](https://github.com/apcg2/emotion-vault/releases/tag/v0.2.0)，但新版不会调用它。
- 清理浏览器数据不会删除已经保存到磁盘的 JSON。尚未保存的输入仍可能因关页、刷新或崩溃丢失，操作进行中请不要关闭页面。
- **全部内容是明文**，能访问 JSON 的人都能看到日志。不要把数据文件上传到 GitHub、共享文件夹或公共网盘。
- 程序不自动联网；数据只在你选择的文件和本次页面内存中。没有 localStorage、sessionStorage、IndexedDB 或后台同步。
- “下载副本”保存当前已加载记录的明文 JSON 副本，适合额外备份；请确认下载完成。换电脑时携带 HTML 和日志 JSON，而不只是 HTML。
- 请只用一个页面编辑同一份日志。程序使用独占写入并检查文件变化；发现其他页面或程序改动时拒绝覆盖，需重新打开文件。不能保证阻止其他桌面程序在任意时刻编辑磁盘文件。
- 权限拒绝、磁盘不足等写入失败会提示错误；结果不确定时要求重新打开核对，不把内存内容冒充已保存。日志文件上限 16 MB。
- “新建”不会覆盖已有内容；选到现有文件会提示改用“打开日志文件”。打开错误或损坏的文件不会替换当前已加载记录。

## 功能

五步日志、情绪前后评分、认知扭曲说明与示例、积极回应与相信程度；周/月日历、时间筛选与趋势分析；完整只读详情和确认删除，不编辑历史。历史和分析直接进入，不再验证密码。

可选演示页仍为地址末尾 `#demo-data`。须先在首页打开一个日志文件，再明确点击导入，才会写入此前七天的标注模拟记录。默认不导入，也不包含任何使用者的数据。

## 完整源码（仅开发者需要 Node.js）

```text
app/                       界面、样式、模拟数据页
components/                只读详情和界面基础组件
lib/local-file.ts          明文格式校验、文件读写、冲突和失败处理
lib/demo-logs.ts            手动演示数据生成
scripts/build-html.mjs     打包单文件 HTML 和依赖许可证
test/                      文件存储、只读详情和单文件测试
dist/emotion-vault.html    构建成品（通过 Releases 分发）
```

开发环境使用 `.nvmrc` 中的 Node 24.16.0，依赖版本由锁文件固定。在项目根目录执行：

```sh
npm ci
npm run lint
npm test
npm run build
```

成品内嵌 React、图表库、CSS、图标和第三方许可证，没有外部模块、CDN 或服务器依赖。密码弹窗、加密/解密和浏览器存储模块已移除。开发预览仍可用 `npm run dev`，仅监听本机 3001 端口，日常双击 HTML 不需要它。

若 agent 安装源码遇到权限拒绝，申请正式授权；仍被拒则停止，由用户在系统终端完成。不得停用或绕过 broker、shim、沙箱。普通使用者下载 HTML，无需安装流程。

## 验证范围

测试用合成数据覆盖明文读写、重新打开、删除、格式/大小校验、拒绝覆盖、权限与磁盘失败、保存结果不确定、并发及冲突；还在临时磁盘目录中验证中文/空格路径、跨实例读取，以及单文件无浏览器存储/加密代码、只读详情和转义。不会访问真实用户数据。

[Windows / macOS 自动检查](https://github.com/apcg2/emotion-vault/actions/workflows/windows.yml) 运行静态检查、测试和构建。这不等于桌面原生文件选择器或 file:// 全流程人工验证。工具阻止本地文件导航时不绕过策略。

人工验收：双击 HTML → 新建独立测试 JSON → 保存合成日志 → 查看历史和分析 → 关闭重开并选择该 JSON → 删除并再次重开确认。权限对话框由本人操作，请勿用真实日志做破坏性测试。
